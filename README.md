# matplotlib-student-performance-analysis

## Overview
This project demonstrates basic data visualization techniques using Python's Matplotlib library. The goal is to analyze student performance data and present insights using different types of charts.

## Visualizations Implemented
- Line Plot: Relationship between study hours and marks obtained
- Scatter Plot: Individual data points showing correlation between study hours and marks
- Grouped Bar Chart: Comparison of Math and Science scores across students
- Histogram: Distribution of marks among 50 students
- Pie Chart: Distribution of students participating in different activities

## Technologies Used
- Python
- Matplotlib
- NumPy

## Key Learning Outcomes
- Creating different types of plots in Matplotlib
- Customizing plots with labels, titles, and legends
- Understanding data distributions using histograms
- Comparing categorical data using bar charts
- Representing proportions using pie charts
